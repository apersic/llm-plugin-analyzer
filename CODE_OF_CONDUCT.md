# Code of conduct

This crate is a first public Rust app and a graph of other people's chat transcripts. Be precise. Be kind. Do not be cruel.

## Expected

- Critique the code, the verdict, or the docs. Do not attack the person.
- Say when you are guessing. A wrong HIT/MISS call is a bug, not a character flaw.
- Do not paste API keys, `.env` files, or raw Cursor transcripts into issues or pull requests. Redact first.
- Do not use this project to harass, dox, or pile on.

## Not welcome

Harassment, slurs, threats, sexual attention that was not asked for, and publishing someone's private data. That includes dumping a transcript that names a coworker or a customer.

## How to report

Open a [private security advisory](https://github.com/apersic/llm-plugin-analyzer/security/advisories/new) if you can. If the repo has no advisory form yet, email the maintainer through GitHub. Do not file a public issue that repeats the abuse.

I will read it, decide, and say what I did. Outcomes range from a warning to a ban on issues and PRs.

This is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/). The rules above are the ones that apply here.
